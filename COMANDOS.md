# Comandos Útiles

## Ejecutar la app
```bash
flutter run
```

## Compilar APK
```bash
flutter build apk --release
```

## Regenerar iconos (si cambias el logo)
```bash
flutter pub run flutter_launcher_icons
```

## Limpiar proyecto
```bash
flutter clean
flutter pub get
```

## Ver dispositivos conectados
```bash
flutter devices
```
